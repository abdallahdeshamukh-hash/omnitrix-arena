# Omnitrix Arena 🛸

A Ben 10 fan game — survive endless waves of Vilgax's drones by cycling through the Omnitrix and picking the right alien for the right threat.

Play it by opening `index.html` in any browser. No dependencies, no install — one file, works offline, desktop and mobile.

## How to play

- Transform into aliens to fight; every alien drains the Omnitrix energy bar, and hitting zero forces you back into **Ben** until it recharges.
- Counter-pick: Heatblast for range, Four Arms for crowds, XLR8 to blitz, Diamondhead to tank, Ghostfreak to phase, Grey Matter to poke.
- **Every 5th wave, Vilgax himself attacks** — a giant boss with eye lasers, a ground-slam shockwave, radial bullet bursts, and drone summons. He enrages below half health. Beat him for a huge score bonus, HP, and a full Omnitrix recharge.

### Controls (desktop)

| Input | Action |
|---|---|
| WASD / arrows | Move |
| Mouse | Aim |
| Space / click | Fire |
| **Scroll wheel + click**, or Q/Tab | Omnitrix dial (slow-mo select) |
| 1–6 | Quick alien pick |
| E | Transform / revert |
| P / Esc | Pause |
| M | Mute |

### Controls (touch)

- Left half: move joystick • Right half: aim + fire
- ⟳ / alien bar: Omnitrix dial • GO ALIEN: transform • ⏸: pause

## Difficulty

Easy / Medium / Hard selectable on the menu (keys 1–3). Best score is saved locally.
